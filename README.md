This is a collection of crude test programs to experiment with various FTC SystemCore functions.
This work is currently being performed with Alpha 6 WPILIB code.

-Alpha Mecanum is a basic timed robot project for a legacy mecanum drive
-Alpha Parameters is an opmode to generate kS and kV values for a legacy Gobilda motor
-Alpha PID is a program that tests PIDF values for a legacy velocity controlled motor
-Alpha IMU is just displaying the various axis rotations to verify that they are consistant with.... something.
-Alpha A301 is just some basic motor run code for general testing... it will change as needed 
-Alpha KiwiDrive is a legacy opmode that runs a 3-wheel kiwi drive robot.  Code was taken from Youtube video.
